# Insight Company — Premium Cinematic Digital Agency Website

An award-winning, production-quality digital experience built for **Insight Company**, an elite creative marketing agency. Designed and engineered as a high-end interactive portfolio and agency showcase following the brand's official visual identity established in their Instagram promotional campaigns.

---

## 🛠️ Technology Stack

- **Framework**: React 18 with TypeScript
- **Bundler & Tooling**: Vite 5
- **Styling**: Tailwind CSS with custom emerald & neon color tokens
- **Motion & Transitions**: Framer Motion (spring curves, layout animations, scroll progress)
- **Icons**: Lucide React
- **Micro-Interactions**: Canvas Confetti

## 💻 How to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
